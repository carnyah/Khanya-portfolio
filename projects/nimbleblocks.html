MOBILE APPLICATION · 03

NimbleBlocks

A strategic mobile block-removal game featuring multiple difficulty levels, player and computer game modes, character selection, timed gameplay and score tracking.

C# Xamarin.Forms XAML

CONCEPT

Strategy, timing and decision-making.

NimbleBlocks is a strategic block-removal game in which players take turns removing blocks from rows while trying to take the final block.

The application combines game logic, user interaction, timers and multiple gameplay configurations into one mobile experience.

GAME FEATURES

Built for different play styles.

01

Difficulty Levels

Players can choose different time-based difficulty levels before starting a game.

02

Game Modes

Supports player-versus-computer and player-versus-player gameplay.

03

Character Selection

Players can select characters before entering gameplay.

04

Timed Gameplay

Countdown timers introduce an additional strategic challenge during play.

05

Score Tracking

The application tracks wins and game outcomes across sessions.

06

Game Results

Players receive clear result states and options to play again or change difficulty.

GAMEPLAY

From menu to match.

Selected views demonstrating the gameplay flow.

LEARNING

Turning game rules into working logic.

This project gave me practical experience in translating game rules into application logic and responding to user actions in real time.

It also strengthened my understanding of interface design, application state and interactive programming in a mobile environment.
