DESKTOP APPLICATION · 04

Ultra Travels

A desktop travel booking system designed to support travel-related services including flights, hotels and car bookings.

C# Windows Forms .NET Framework

OVERVIEW

Bringing travel services into one system.

Ultra Travels is a desktop booking application designed to organise travel-related services within one system.

The application brings together core travel functions such as flights, hotels and vehicle rentals while providing supporting functionality for users and administration.

KEY FEATURES

Core travel functionality.

01

Flight Booking

Provides functionality for managing flight-related bookings.

02

Hotel Booking

Supports hotel-related travel arrangements within the booking system.

03

Car Booking

Incorporates vehicle rental functionality as part of the travel experience.

04

User Management

Includes user-related functionality supporting interaction with the application.
