WEB APPLICATION · 01

Ubuntu Meals

A food donation and distribution platform designed to connect food donors, NGOs and volunteers with communities in need.

C# ASP.NET SQL Server HTML CSS JavaScript

OVERVIEW

Bridging surplus food with communities.

Ubuntu Meals is a web-based platform focused on facilitating food donation and redistribution.

The system brings different users together within one platform, allowing food donations to be managed while recipients can browse available food and submit requests.

KEY FEATURES

What the system does.

01

Food Donations

Allows donors to provide information about available food and quantities.

02

Food Requests

Allows recipients to browse available donations and submit requests.

03

User Roles

Supports different roles and interactions within the platform.

04

Request Tracking

Provides functionality for users to monitor food requests and their status.
