WEB APPLICATION · 02

WhatWaste

A waste management and recycling platform designed to support waste-related activities, user interaction and system management.

C# ASP.NET SQL Server HTML CSS JavaScript

OVERVIEW

Making waste management more accessible.

WhatWaste is a web-based information system developed around waste management and recycling.

The project explores how technology can support users in interacting with waste-related services while providing structured functionality for managing information within the system.

KEY FEATURES

What the system provides.

01

User Management

Supports account-related functionality and user interaction within the platform.

02

Waste Records

Provides functionality for recording and managing waste-related information.

03

Recycling

Incorporates recycling-focused functionality into the overall system experience.

04

System Administration

Includes management functionality supporting administration of the platform.
